# AI Customer Retention Platform — Documentation

## Project

AI-powered B2B SaaS platform that helps organizations identify, prioritize, and retain customers at risk of churn.

## Core Loop

Detect → Prioritize → Explain → Recommend → Execute → Measure → Learn

## Repository Structure

### frontend/
Web application built with Next.js, React, and TypeScript.

### backend/
FastAPI backend responsible for APIs, authentication, customer data, AI actions, and business logic.

### ml/
Machine-learning components for churn prediction, risk scoring, and explainability.

### database/
Database schemas and database-related resources.

### docs/
Product, architecture, and technical documentation.
