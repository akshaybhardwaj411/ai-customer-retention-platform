# AI Customer Retention Platform — Machine Learning

This folder contains the machine-learning components of the platform.

## Responsibilities

- Customer feature engineering
- Churn prediction
- Risk scoring
- Customer segmentation
- Model evaluation
- Prediction generation
- Explainability with SHAP
- Model versioning

## Initial Model

The MVP will begin with a customer churn prediction model.

The model will estimate:

- Churn probability
- Risk level
- Important factors influencing the prediction

The prediction will later feed into the Risk Center and Action Center.
